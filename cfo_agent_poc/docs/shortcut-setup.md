# iPhone 快捷指令「记一笔」搭建指南

整个采集链路里，唯一要在手机上做的就是这个快捷指令。它只做两件事：**截屏 → 把截图直接 POST 到你的账本**。不用配邮箱，不用开 IMAP，也不需要在网页上点「同步」。搭好之后，日常使用就是「支付 → 打开账单详情页 → 点一下」。

下文用 `https://cfo.example.com` 代表服务的访问地址，请换成你自己的域名。网页「记一笔」弹窗里显示的「上传地址」就是要填的完整地址。

> 💡 管理员发布了现成的快捷指令时，网页「记一笔」弹窗里会出现「安装快捷指令」按钮：点开安装，按提示粘贴上传密钥即可，不用往下手搭。

## 一、准备：生成上传密钥

1. 用电脑或手机登录网页，点右上角 **「记一笔」**
2. 在「连接 iPhone」里点 **「生成上传密钥」**，复制以 `cfo_up_` 开头的那串字符

上传密钥**只能往你的账本里传截图，读不到任何账单数据**。即使泄露，别人也看不到你的账。密钥只在生成时显示一次；忘了或者换手机时，重新生成一个就行，旧密钥会立刻失效。

## 二、搭建步骤

打开「快捷指令」App → 右上角 **+** 新建，依次添加以下操作：

1. **文本**：内容粘贴你的上传密钥（`cfo_up_…`）
2. **截屏**（Take Screenshot）
3. **获取 URL 内容**（Get Contents of URL），展开后逐项配置：
   - **URL**：`https://cfo.example.com/api/v1/captures`
   - **方法**：`POST`
   - **头部**：新增一项，键填 `Authorization`，值填 `Bearer `（Bearer 后面有一个空格）再插入第 1 步的「文本」变量
   - **请求体**：选 **文件**，插入第 2 步的「截屏」变量
4. **获取词典值**：获取「URL 的内容」里键为 `message` 的值
5. **显示通知**：内容选上一步的「词典值」

给快捷指令命名为「记一笔」，建议：

- 设置「辅助功能 → 触控 → 轻点背面」双击触发，体验最顺滑；或者
- 添加到主屏幕

每次触发后会弹出一条通知，内容就是服务端的识别结果：

| 通知 | 含义 |
|---|---|
| `已记账 ¥32.50 · 美团外卖` | 成功入账。同一笔交易再截一次也是这条：按交易单号合并成一笔，以最新这张截图为准 |
| `已收到，但支付时间没认出来，请到网页里补全` | 入账了，但缺字段，暂不计入统计，在网页「待订正」里补一下 |
| `这张截图记过了：…` | 同一个图片文件又传了一次（多见于网页上传选重了），不会再识别 |
| `已收到，正在识别，稍后在网页里查看` | 识别超过 8 秒，或识别出错正在自动重试，后台会接着处理 |
| `识别失败：…` | 自动重试 3 次仍失败，重新触发一次，或在网页上传这张截图 |
| `上传密钥无效或已失效…` | 密钥被重新生成或停用了，换成新密钥 |
| `上传太频繁了，请过几分钟再试。` | 10 分钟内超过 60 张 |

> 第一次运行时，iOS 会询问是否允许连接你的域名，选 **「始终允许」**，之后就不会再问。

## 三、日常使用

1. 微信 / 支付宝支付完成后，**打开这笔账单的详情页**
2. 确认页面里能看到 **金额、支付时间、商户 / 商品、支付方式**（解析需要这些字段）
3. 触发「记一笔」→ 看到「已记账」通知就完成了，网页刷新即可看到

> 小技巧：微信在「我 → 服务 → 钱包 → 账单」，支付宝在「我的 → 账单」里都能补录历史交易。逐笔打开详情页触发快捷指令即可；在电脑上也可以用网页「记一笔 → 上传截图」一次选多张。

## 四、发布一键安装链接（管理员）

想让用户不用手搭，可以把你的快捷指令分享成 iCloud 链接：

1. 把第 1 步「文本」里的密钥**清空**，然后在快捷指令设置里给这个「文本」操作添加 **导入问题**（Import Question），问题写「粘贴网页『记一笔』里生成的上传密钥」。这样别人安装时会被要求粘贴自己的密钥
2. 确认 URL 是正式域名
3. 快捷指令 App → 长按「记一笔」→ **分享 → 拷贝 iCloud 链接**
4. 把链接填进服务器 `.env` 的 `CFO_SHORTCUT_URL`，重启服务。之后网页「记一笔」弹窗里就会出现「安装快捷指令」按钮

**分享前务必检查**：快捷指令里不能留着你自己的密钥。

## 常见问题

| 问题 | 排查 |
|---|---|
| 通知显示「上传密钥无效」 | 密钥被重新生成或停用了；在网页重新生成，把新密钥粘到第 1 步的「文本」里 |
| 通知显示「HEIC 图片，暂不支持」 | 在「截屏」和「获取 URL 内容」之间加一步 **转换图像 → JPEG** |
| 通知显示「截图太大了」 | 同上，转成 JPEG 能把体积降下来 |
| 没有任何通知 | 检查 URL 是否完整（结尾 `/api/v1/captures`）、头部是不是 `Bearer ` 加空格加密钥 |
| 解析字段不全 | 截图时账单详情页是否完整展示了金额、时间、商户；不要截半屏 |
| 同一笔记成了两笔 | 系统靠截图里的交易单号 / 订单号 / 转账单号认出同一笔。截图里没有单号时（比如支付宝缴费，订单号收在「更多」里没展开），每截一次都会当成新的一笔。在网页里删掉多出来的那笔即可 |
| 想在电脑上手动补账 | 网页「记一笔 → 上传截图」，支持多选 PNG / JPEG |
